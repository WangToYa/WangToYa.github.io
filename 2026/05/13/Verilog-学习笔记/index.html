Verilog 的本质不是“写程序”，而是“描述电路”。

🧠 什么是 Verilog

Verilog 是一种硬件描述语言（HDL）。

它主要用于：

  • FPGA 开发
  • CPU 设计
  • 数字芯片设计
  • 通信协议实现
  • 时序逻辑控制

📌 Verilog 与 C 语言的区别

C 语言 Verilog
描述程序执行过程 描述硬件连接关系
顺序执行 并行运行
操作数据 搭建电路
面向 CPU 面向数字逻辑

⚡ 组合逻辑与时序逻辑

🔹 组合逻辑

特点：

  • 没有时钟
  • 没有状态
  • 输入变化输出立即变化

🔹 时序逻辑

特点：

  • 依赖时钟
  • 可以存储状态

🧩 状态机 FSM

FSM（有限状态机）是数字系统设计核心。

常用于：

  • UART
  • CPU 控制器
  • 交通灯
  • 自动售货机

🧱 wire 与 reg

🔹 wire

表示导线。

通常用于：

  • assign
  • 模块连接

🔹 reg

表示 always 中可赋值变量。

⚠️ 注意：

reg 不一定是真正寄存器。

它只是 Verilog 的一种变量类型。

📚 如何学习 Verilog

这是我目前觉得比较有效的方法。

🌱 第一阶段：基础语法

重点：

  • module
  • assign
  • always
  • reg / wire
  • if / case

建议：

多写小模块：

  • 加法器
  • 计数器
  • 分频器
  • 流水灯

🌿 第二阶段：时序逻辑

重点：

  • 时钟
  • 复位
  • FSM
  • FIFO

建议：

开始写：

  • UART
  • SPI
  • 数码管驱动

🌳 第三阶段：系统设计

重点：

  • 模块化
  • 总线
  • CPU
  • 流水线

这个阶段会真正理解：

Verilog 是在“搭电路”。

刚开始学习 Verilog 的时候，我一直想：

“为什么这东西和编程这么不一样？”

后来才慢慢理解：

数字电路设计本来就不是软件开发。

当真正开始：

  • 画数据通路
  • 写状态机
  • 分析时钟
  • 看波形图

的时候，才会逐渐进入硬件设计的世界。
